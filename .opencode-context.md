# Mapa del Proyecto — Control de Equipos 3.0

## 1. Arquitectura
- **Tipo:** Monolito desacoplado + distribución portable. Frontend Vite/React SPA desacoplado de backend Express, REST + Socket.IO. Portable es carpeta `Version-Portable/` con `node.exe` + `backend/` + `frontend/dist`, lanzada por `.bat` que abre `http://localhost:3001` (backend sirve `frontend/dist` como estático en producción).
- **Flujo offline portable:** `iniciar.bat` -> `node.exe backend/node_modules/tsx/dist/cli.mjs backend/server.ts` (PORT 3001, NODE_ENV production, DB `Version-Portable/backend/equipos.db`, STATIC `Version-Portable/frontend/dist`) -> navegador.
- **Modos:** Dev (`backend pnpm run dev` + `frontend pnpm run dev` HMR 5300), Prod portable (`Version-Portable/iniciar.bat`).

## 2. Stack Crítico
- **Frontend:** React 19.2 + Vite 7.3 + TypeScript 6.0 + Tailwind 4.2 + MUI 9.2 + Recharts 3.7 + Framer Motion 12 + Socket.IO-client 4.8. Build: `vite build` -> `frontend/dist` (40s). Dev 5300, prod servido por backend 3001.
- **Backend:** Node 22.22 + Express 4.22 + SQLite3 6.0.1 + tsx 4.22 + Pino 10.3 + Helmet + CORS + RateLimit. `server.ts` (tsx) con `app.ts` (`STATIC_PATH=../frontend/dist` o env, `DB_PATH=../equipos.db` o env). `.env` en `backend/.env`. DB: `backend/equipos.db` (WAL, busy_timeout 5000). Migraciones en `db/migrations/runner`.
- **Portable:** `Version-Portable/node.exe` (Node 22 x64, 83MB) + `backend/` (prod deps shamefully-hoist) + `frontend/dist` + `iniciar.bat`/`iniciar-app.bat` (Edge --app fallback Chrome). `scripts/sync-portable.ps1` espeja source -> portable (preserva `equipos.db` y `.env` del portable).
- **Build portable:** `pnpm run build:portable` = `pnpm run build` + `powershell scripts/sync-portable.ps1`. Sync detecta cambio de `pnpm-lock.yaml` para reinstalar prod deps.

## 3. Convenciones
- **Package manager:** pnpm 11.9. Workspace `onlyBuiltDependencies: '@swc/core'` sin globs, por eso `pnpm --filter` no funciona — usar `cd backend/frontend` directo. Portable usa `pnpm install --prod --shamefully-hoist`.
- **Scripts:** `frontend build: "vite build"` (sin NODE_OPTIONS, falla en PowerShell). Backend `start: "tsx server.ts"`, `dev: "nodemon"`. Raíz `build:portable`, `portable:sync`, `portable:quick`.
- **Rutas:** Backend dev y portable `http://localhost:3001`, frontend dev `vite --port 5300`.
- **DB:** `database.ts` usa `DB_PATH` env o `../equipos.db`. `SCHEMA_VERSION` bump al agregar tablas. WAL + busy_timeout 5000.
- **Seguridad:** Helmet CSP con nonce injection, JWT_SECRET/ADMIN_PASSWORD validados al boot.

## 4. Puntos de Dolor / Deudas
- **Node en Windows:** `NODE_OPTIONS=... vite build` no funciona en PowerShell. Usar `vite build` directo.
- **Portable en Program Files:** No copiar Version-Portable a `C:\Program Files` (read-only, DB no escribe). Usar Escritorio/USB/C:\App.
- **Sync portable:** `Version-Portable/` es gitignored (contiene node.exe y build). Fuente es `frontend/` + `backend/`; portable es espejo vía `scripts/sync-portable.ps1`. No editar portable directo.
- **Puerto 3001:** Si ocupado, `EADDRINUSE` y `iniciar.bat` falla — cerrar otra instancia `taskkill /IM node.exe`.
