# Mapa del Proyecto — Control de Equipos 3.0

## 1. Arquitectura
- **Tipo:** Monolito desacoplado. Frontend Vite/React SPA desacoplado de backend Express, REST + Socket.IO. Sin distribución portable (eliminada 2026-10-15: `scripts/sync-portable.ps1`, `backend/scripts/merge-portable-users.js`, `PORTABLE_MODE` y `VITE_PORTABLE_MODE` removidos por exponer `.env` y hashes en USB).
- **Modos:** Dev (`backend pnpm run dev` + `frontend pnpm run dev` HMR 5300), Prod (backend 3001 sirve `frontend/dist` como estático; nube vía worker Cloudflare + D1).

## 2. Stack Crítico
- **Frontend:** React 19.2 + Vite 7.3 + TypeScript 6.0 + Tailwind 4.2 + MUI 9.2 + Recharts 3.7 + Framer Motion 12 + Socket.IO-client 4.8. Build: `vite build` -> `frontend/dist` (40s). Dev 5300, prod servido por backend 3001.
- **Backend:** Node 22.22 + Express 4.22 + SQLite3 6.0.1 + tsx 4.22 + Pino 10.3 + Helmet + CORS + RateLimit. `server.ts` (tsx) con `app.ts` (`STATIC_PATH=../frontend/dist` o env, `DB_PATH=../equipos.db` o env). `.env` en `backend/.env`. DB: `backend/equipos.db` (WAL, busy_timeout 5000). Migraciones en `db/migrations/runner`.

## 3. Convenciones
- **Package manager:** pnpm 11.9. Workspace `onlyBuiltDependencies: '@swc/core'` sin globs, por eso `pnpm --filter` no funciona — usar `cd backend/frontend` directo.
- **Scripts:** `frontend build: "vite build"` (sin NODE_OPTIONS, falla en PowerShell). Backend `start: "tsx server.ts"`, `dev: "nodemon"`.
- **Rutas:** Backend `http://localhost:3001`, frontend dev `vite --port 5300`.
- **DB:** `database.ts` usa `DB_PATH` env o `../equipos.db`. `SCHEMA_VERSION` bump al agregar tablas. WAL + busy_timeout 5000.
- **Seguridad:** Helmet CSP con nonce injection, JWT_SECRET/ADMIN_PASSWORD validados al boot.

## 4. Puntos de Dolor / Deudas
- **Node en Windows:** `NODE_OPTIONS=... vite build` no funciona en PowerShell. Usar `vite build` directo.
- **Puerto 3001:** Si ocupado, `EADDRINUSE` — cerrar otra instancia `taskkill /IM node.exe`.
